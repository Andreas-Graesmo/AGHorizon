# The sources of the ffmpeg builds that AG Horizon shipped before 3.1 (MIGRATION_PLAN.md 5.9, best effort), read by
# scripts/ffmpeg-legacy-source.sh. These builds came from ffmpeg-static 5.3.0 (its release b6.1.1):
#   win      Electron <= 2.6.0 on Windows, and 3.1.0-beta.0: gyan.dev 6.1.1 "essentials" (win32-x64)
#   linux    the Electron AppImage: John Van Sickle's static 7.0.2 (linux-x64)
#   mac      the Electron Mac app (Apple silicon): osxexperts.net's 6.0 (darwin-arm64)
# Their makers publish no build scripts, and pin some libraries nowhere. Each line says how its version was found:
#   exact    named by the build (its README, or the version the binary reports)
#   nearest  not named anywhere: the release, or the commit, current when the build was made
#
# os  name  version  exact|nearest  kind  source  [ref]
#   kind git      source = repository, ref = tag or commit (short ones are resolved)
#   kind gitdate  source = repository, ref = the last commit before this date on the default branch
#   kind x264rev  source = repository, ref = x264's revision number (its commit count)
#   kind url      source = a release archive
#   kind debsrc   source = Debian source package, ref = its version (snapshot.debian.org)
